## 5. 未確認（検証済みと言えないもの）

- **iPhone・Android・iPad の実機では試していません。** 画面の大きさをまねた Chrome での確認だけです。
- **Safari（iPhone / iPad）と Firefox では試していません。** 特に次は実機で確かめが要ります。
  - iPhone の Safari での「ホーム画面に追加」とオフライン起動
  - iPhone のコピー（Safari の制限で、ボタンを押した操作の中でしかコピーできない。作りはそれに合わせている）
  - 数字キーボードの出方（`inputmode="decimal"`）
- 公開先（HTTPS）は Chrome での確認のみ（下の 6）。
- PC の確認は、画面なしの Chrome による自動操作です。人の目でのブラウザ操作はしていません。
